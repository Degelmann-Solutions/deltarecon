<SectionHeading id="what-it-does">Was DeltaRecon tut</SectionHeading>

<Prose>

Die Veränderungsanalyse kennen Sie aus Bilanz und Solvency II: eine Überleitung vom Vorjahr auf den aktuellen Stand, Schritt für Schritt. DeltaRecon nimmt als Schritte die <Term id="revision">Revisionen</Term> des versionierten Berechnungsprogramms. Jede Revision ist eine Änderung. Zwischen Release N und dem Stand N+1 rechnet DeltaRecon Stände, vergleicht sie und ordnet die <Term id="deviation">Abweichung</Term> in einer Größe den einzelnen Revisionen zu, die sie verursachen.

Jedes Ergebnis stammt aus Rechnungen und Vergleichen, die jedes Mal dasselbe Ergebnis liefern. DeltaRecon verwendet keine Agenten.

Das Bild zeigt das Beispiel des Quick Starts am <Term id="reference-model">Referenzmodell</Term>: Der Stand N+1 liegt {facts.revisions} Revisionen nach Release N, und {deviating} davon weichen im <Term id="bruttobeitrag" /> ab.

</Prose>

<SectionHeading id="what-you-need">Was Sie brauchen</SectionHeading>

<Prose>

Einen Computer mit Windows oder Linux. Sie laden ein Archiv herunter und entpacken es. Installiert wird nichts: Das Paket enthält alles, was es braucht, auch das Referenzmodell, eine Risikolebensversicherung mit {facts.modelPoints} Modellpunkten. Das Referenzmodell führt die Mechanik vor und ist kein Bewertungsmodell; sein Bestand ist synthetisch und enthält keine Kundendaten.

</Prose>

<SectionHeading id="what-you-get">Was Sie bekommen</SectionHeading>

Die geführte Vorführung des Quick Starts läuft in vier Schritten und zeigt drei Tabellen. Jeder Lauf hinterlässt außerdem einen <Term id="record">Nachweis</Term>, womit was gerechnet wurde: Code, Parameter und Bestandsdaten.
