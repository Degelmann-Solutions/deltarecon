<Callout tag="The output in plain words" title="How to read the output of a search">

`search: searched` The search computed {provisionen.run} of the {provisionen.walk} states: release N and one state after each change. It did not need the other {provisionen.saved}.

`state 0`, <code>state {provisionen.walk - 1}</code> The search computed both ends again, and each gave the recorded result.

`held: input_data` The <Term id="input-data">portfolio data</Term> stay at release N in every state. One <Term id="revision">revision</Term> changes the table of the <Term id="model-point">model points</Term>; the search does not show its effect.

`contribution from state …` A revision that changes the <span lang="de">Provisionen</span> on its own. The line names the revision in full; the tables of the demo show its first seven characters. The state after the revision has the number of the change in the table of the changes: the largest sum here belongs to change {change(largest.short).number}, “<span data-no-term>{change(largest.short).description}</span>”.

`sum` The signed sum of “state after the revision minus state before it” over all model points and the periods 0 to 59, as in the table of the demo. `absolute sum` adds the same differences without their sign.
